# 灵伴世界（LingPal World）· 公开 Demo

AI 宠物 × 3D 探索世界 × 实体盲盒的网页游戏演示站，托管于 GitHub Pages，全网可扫码访问。

- 2D 小世界游戏：[web2d/](web2d/)
- 宠物展示：[web2d/showcase.html](web2d/showcase.html)
- 盲盒扫码页：[web2d/qrcodes.html](web2d/qrcodes.html)
- 手机壳交互 Demo：根目录 [index.html](index.html)（点「🎮 网页游戏」进入游戏）

> 公网静态托管不含本地激活服务，扫码后自动进入围观模式；完整防伪激活需部署后端（见主仓库 [Lukex-Collab/Yaya](https://github.com/Lukex-Collab/Yaya)）。
